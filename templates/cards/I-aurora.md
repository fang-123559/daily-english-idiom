# I · 极光暗夜 — 卡片生成规范

> 画布 `viewBox="0 0 680 520"`。字体：英文标题/音标 `Georgia,'Times New Roman',serif`；中文 `'PingFang SC','Microsoft YaHei',sans-serif`。
> 成品示例：同目录 `I-aurora.svg`。需替换的内容：{日期} {俗语} {音标} {四段文案}。

## 元素参数

- **页面背景**：全幅 `#0B0E1A`
- **极光**（radialGradient，中心色→透明）：椭圆 (200,0) 300×150 `#22D3EE` 28%；(480,-20) 280×140 `#8B5CF6` 32%；(340,10) 200×110 `#EC4899` 22%
- **星星**：5 颗小圆点 #FFFFFF，opacity 0.4–0.7，散布卡片外顶部区域（如 120,90 r1.5 / 162,66 r1 / 602,120 r1.5 / 95,150 r1 / 620,70 r1）
- **玻璃卡**：x70 y40 540×440 rx20 fill `#131930` opacity 0.95；叠加同尺寸 fill none stroke 线性渐变 `#22D3EE→#8B5CF6` 1px（渐变描边是核心特征）
- **日期胶囊**：x486 y60 104×30 rx15，fill none stroke `#22D3EE` 1px opacity 0.9；文字居中 x538 y79，13px 500 `#7DE3F4`，格式「M月D日」
- **标题**：居中 x340 y130，Georgia 700，**34px**（次级 27px；>32 字符拆两行，行高 34），fill `#F4F6FF`
- **音标**：居中 x340 y158，14px `#7C86A8`
- **强调条**：x270 y170 140×4 rx2，三色渐变 `#22D3EE → #8B5CF6 → #EC4899`
- **分隔线**：x100→580，y192，`#232B47` 1px
- **四段标签**：霓虹竖线 x100 w4 h24 rx2 + 文字 x114 13px 600 同色；正文 x180 13px `#C9D1E8`

| 段 | 竖线 y | 标签色 | 文字 baseline |
|---|---|---|---|
| 含义 | 200 | #A78BFA | 217 |
| 例句 | 246 | #34D399 | 263（第二行 279） |
| 来源 | 308 | #FBBF24 | 325 |
| 记忆 | 362 | #F472B6 | 379 |

- **俗语高亮**：`<tspan font-weight="700" fill="#34D399">`
- **页脚**：y455 居中 12px `#5A6486`；两侧短线 y451：x140→235、x445→540，`#232B47` 1px

## 该款注意

- 暗底配色逻辑：正文用低亮灰蓝 `#C9D1E8`，彩色只给标签、强调条、俗语，正文不要纯白（太刺眼）
- 标题拆两行时：基线 y112 / y146，音标 y172，强调条 y184，分隔线 y206，四段整体 +14 顺排
