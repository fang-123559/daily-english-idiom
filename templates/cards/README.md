# 卡片模板库

每日俗语卡片支持 8 款视觉模板。在 `memory.md` 顶部「配置」区设置 `卡片模板: {编号}` 即可切换，下次执行生效；也可设为 `ROTATE` 按周轮换。

| 编号 | 风格 | 规范文件 | 预览 | 特点 |
|---|---|---|---|---|
| A | 轻改紫卡（默认） | A-refined.md | A-refined.svg | 白卡柔影 + 衬线标题 + 浅彩胶囊标签 |
| B | 手账风 | B-journal.md | B-journal.svg | 奶油底 + 和纸胶带 + emoji 标签 + 涂鸦 |
| C | 极简编辑 | C-minimal.md | C-minimal.svg | 左对齐 + 中英双行标签 + 细线分隔，单一强调色 |
| F | 复古报纸 | F-retro.md | F-retro.svg | 旧纸色 + 双线框 + 单色印刷 + 红色点缀 |
| G | 便利贴 | G-sticky.md | G-sticky.svg | 黄便签 + 胶带折角 + 荧光笔标记 |
| I | 极光暗夜 | I-aurora.md | I-aurora.svg | 深空底 + 极光 + 玻璃卡 + 霓虹竖线标签 |
| J | 蜜桃盐系 | J-peach.md | J-peach.svg | 彩旗 + 圆形日期徽章 + 底部波浪 + 蜜桃单色系 |
| K | 横线笔记本 | K-notebook.md | K-notebook.svg | 打孔活页纸 + 红 margin 线 + 文字压 26px 横线网格 |

## 如何使用

1. 打开想用的 `.svg` 文件预览效果
2. 在 `memory.md` 顶部「配置」区填：`卡片模板: G`（换成你选的编号）
3. 之后每次执行，任务会读取对应的 `.md` 生成规范来绘制卡片

## 轮换模式

`卡片模板: ROTATE` 时，按当年第几周对 8 取模，从 [A, B, C, F, G, I, J, K] 中选一款，每周一换。

## 通用适配规则（所有模板共用）

- 标题按字符数分级：≤20 字符用规范标准字号；21–32 字符降为次级字号；>32 字符在语义边界拆两行，后续元素 y 坐标随之下移（各规范中有具体数值）
- 每段内容最多 2 行，超出精简文字，不靠缩小字号硬塞
- 正文每行上限：13px 字号下约 30 个汉字 / 65 个英文字符
