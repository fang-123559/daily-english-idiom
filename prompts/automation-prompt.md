# 自动化任务 Prompt 模板 — 每日英语俗语

> 用途：将本 Skill 接入 WorkBuddy / Claude 等平台的每日定时任务（Automation）。
> 使用前请将下方所有 `{PROJECT_DIR}` 占位符替换为你的实际项目目录绝对路径。

---

每天推荐一条通俗的、英语文化中日常使用的、会在英语口语或书面表达里出现的英语俗语，优先选取生活和职场中常见的俗语。

## 执行流程（必须严格遵守）

### 第零步：确认卡片模板
1. 读取 `{PROJECT_DIR}/memory.md` 顶部「配置」区的 `卡片模板` 字段（如 `卡片模板: G`）
2. 字段缺失 → 默认 `A` 并补写入配置区；字段为 `ROTATE` → 按当年第几周对 8 取模从 [A, B, C, F, G, I, J, K] 中选
3. 编号与规范文件映射见 `{PROJECT_DIR}/templates/cards/README.md`

### 第一步：读取历史记录（避免重复）
1. 读取文件：`{PROJECT_DIR}/memory.md`
2. 找到「历史推荐」表格，获取所有已推送过的俗语列表
3. **严禁**推荐表格中已存在的任何俗语

### 第二步：选择新俗语
- 从常见英语俗语库中选择一条**未在历史记录中**的俗语
- 优先选取：日常生活和职场中高频使用的俗语
- 确保俗语有清晰的含义、来源和记忆点

### 第三步：生成推送内容
按以下**完整格式**输出：

#### 第一部分：SVG 可视化卡片
使用 `show_widget` 生成。打开 `{PROJECT_DIR}/templates/cards/` 下配置对应的规范文件（如 `G` → `G-sticky.md`），严格按其中的坐标、色值、字体参数执行；同目录同名 `.svg` 为成品示例。

通用适配规则（必须遵守）：
- 标题 ≤20 字符用规范标准字号；21–32 字符降为次级字号；>32 字符在语义边界拆两行，后续元素 y 坐标按规范说明下移
- 每段内容最多 2 行，超出精简文字；正文每行约 30 汉字 / 65 英文字符上限
- 段内行距 16px（K 款为 26px 横线网格，基线必须压线，见其规范）
- 例句中的**俗语部分**用 `<tspan font-weight="700">` + 该模板强调色高亮
- 模板规范文件无法读取 → 回退 A 款（`A-refined.md`）

#### 第二部分：卡片下方结构化文字
SVG 卡片输出后，立即输出以下结构化文字（Markdown 格式）：

```
🗣️ **今日英语俗语**

# **"{俗语}"**
/{音标}/

---

📖 **含义**

字面意思是"..."，引申为...。常用来...。日常生活和职场中都非常高频。

---

💬 **例句**

**例句一（场景描述）**
> "{英文例句，俗语部分用 **加粗** 标注}。"
> （中文翻译。）

**例句二（不同场景）**
> "{英文例句，俗语部分用 **加粗** 标注}。"
> （中文翻译。）

---

🌍 **俗语来源**

这句话起源于 **{时期/背景}**。...最早在 {年份} 左右的文献中就有记载。

---

🧠 **记忆小提示**

想象{生动的场景画面}来帮助记忆...所以 **{关键词拆解逻辑}**。

---

💡 **关键词联想：**{关键词} = {含义}，{使用场景提示}。

---

📅 **{YYYY年M月D日}** · 每日一俗语
```

### 第四步：更新历史记录
1. 将本次推荐的俗语、日期、中文含义添加到 `{PROJECT_DIR}/memory.md` 的「历史推荐」表格
2. 在「执行日志」中记录本次执行情况
3. 确保文件编码为 UTF-8

## 输出要求
- 俗语部分用 **加粗** 标注，帮助快速定位
- 例句至少 2 条，涵盖不同使用场景
- 例句中俗语用 **加粗**，中文翻译用括号包裹
- 来源需注明时期、背景、最早文献记载时间
- 记忆小提示需要包含一个生动的场景想象 + 关键词拆解逻辑
- 关键词联想：一句话点睛，关联用法场景
- 日期使用"YYYY年M月D日"格式

## 异常处理
- 模板配置无效或规范文件缺失 → 回退 A 款，记录警告
- memory.md 不存在 → 按 templates/memory-template.md 创建
- 历史表格损坏 → 备份后重建
- 所有俗语已推送 → 清空历史，开始新一轮
- 俗语有冒犯性/含义不清 → 跳过，选下一条
- 写入失败 → 重试一次，仍失败记录到临时文件
- 每次执行后必须确认 memory.md 写入成功（历史记录完整性是去重机制的生命线）
