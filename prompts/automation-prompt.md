# 自动化任务 Prompt 模板 — 每日英语俗语

> 用途：将本 Skill 接入 WorkBuddy / Claude 等平台的每日定时任务（Automation）。
> 使用前请将下方所有 `{PROJECT_DIR}` 占位符替换为你的实际项目目录绝对路径。

---

每天推荐一条通俗的、英语文化中日常使用的、会在英语口语或书面表达里出现的英语俗语，优先选取生活和职场中常见的俗语。

## 执行流程（必须严格遵守）

### 第一步：读取历史记录（避免重复）
1. 读取文件：`{PROJECT_DIR}/memory.md`
2. 找到「历史推荐」表格，获取所有已推送过的俗语列表
3. **严禁**推荐表格中已存在的任何俗语

### 第二步：选择新俗语
- 从常见英语俗语库中选择一条**未在历史记录中**的俗语
- 优先选取：日常生活和职场中高频使用的俗语
- 确保俗语有清晰的含义、来源和记忆点

### 第三步：生成推送内容
按以下**完整格式**输出：

#### 第一部分：SVG 可视化卡片
使用 `show_widget` 生成，严格按以下参数和样式：
- **viewBox**: "0 0 680 520"
- **卡片主体**: x="40" y="20" width="600" height="480" rx="16" fill="#F8F7FE" stroke="#534AB7" stroke-width="1.5"
- **日期胶囊**: x="70" y="45" width="100" height="28" rx="14" fill="#534AB7"，文字 font:500 13px #FFFFFF，text-anchor:middle，x="120" y="64"
- **标题**: font:600 28px fill:#26215C，text-anchor:middle，x="340" y="110"（过长>20字符时拆为两行，字号26px）
- **音标**: font:400 14px fill:#888780，text-anchor:middle，x="340" y="140"
- **分隔线**: x1="70" y1="165" x2="610" y2="165" stroke="#534AB7" stroke-width="1" stroke-opacity="0.3"
- **标签**（统一尺寸 x="100" width="60" height="26" rx="6"，文字 font:500 12px #FFFFFF text-anchor:middle，x="130"）:
  - 含义：fill="#7F77DD"，y="203"
  - 例句：fill="#0F6E56"，y="248"
  - 来源：fill="#BA7517"，y="313"
  - 记忆：fill="#D85A30"，y="378"
- **页脚**: font:400 12px fill="#888780" text-anchor:middle，x="340" y="475"

#### 文本渲染规范（重要）
- 每行使用独立的 `<text x="145" y="起始Y">内容</text>`
- 行间距：16px（如 y="222", y="238", y="254"）
- 例句中的**俗语部分**使用 `<tspan font-weight="700" fill="#0F6E56">` 高亮
- 每段内容最多3行，超出则精简文字

#### 第二部分：卡片下方结构化文字
SVG 卡片输出后，立即输出以下结构化文字（Markdown 格式）：

```
🗣️ **今日英语俗语**

# **"{俗语}"**
/{音标}/

---

📖 **含义**

字面意思是"..."，引申为...。常用来...。日常生活和职场中都非常高频。

---

💬 **例句**

**例句一（场景描述）**
> "{英文例句，俗语部分用 **加粗** 标注}。"
> （中文翻译。）

**例句二（不同场景）**
> "{英文例句，俗语部分用 **加粗** 标注}。"
> （中文翻译。）

---

🌍 **俗语来源**

这句话起源于 **{时期/背景}**。...最早在 {年份} 左右的文献中就有记载。

---

🧠 **记忆小提示**

想象{生动的场景画面}来帮助记忆...所以 **{关键词拆解逻辑}**。

---

💡 **关键词联想：**{关键词} = {含义}，{使用场景提示}。

---

📅 **{YYYY年M月D日}** · 每日一俗语
```

### 第四步：更新历史记录
1. 将本次推荐的俗语、日期、中文含义添加到 `{PROJECT_DIR}/memory.md` 的「历史推荐」表格
2. 在「执行日志」中记录本次执行情况
3. 确保文件编码为 UTF-8

## 输出要求
- 俗语部分用 **加粗** 标注，帮助快速定位
- 例句至少 2 条，涵盖不同使用场景
- 例句中俗语用 **加粗**，中文翻译用括号包裹
- 来源需注明时期、背景、最早文献记载时间
- 记忆小提示需要包含一个生动的场景想象 + 关键词拆解逻辑
- 关键词联想：一句话点睛，关联用法场景
- 日期使用"YYYY年M月D日"格式

## 异常处理
- memory.md 不存在 → 按 templates/memory-template.md 创建
- 历史表格损坏 → 备份后重建
- 所有俗语已推送 → 清空历史，开始新一轮
- 俗语有冒犯性/含义不清 → 跳过，选下一条
- 写入失败 → 重试一次，仍失败记录到临时文件
- 每次执行后必须确认 memory.md 写入成功（历史记录完整性是去重机制的生命线）
